# AIKI Download (aiki.lol)
1. `npm install && npm run dev`
2. Edit `src/config/download.ts` with the real iOS PWA URL, APK URL, version, size, support email and policy URLs. Empty values show "coming soon" instead of a link.
3. Deploy: push to GitHub, import in Vercel, then add `aiki.lol` under Project → Domains.
